# Decisions

| Date | Decision | Reason |
| --- | --- | --- |
| 2026-10-26 | AU and VST3 both ship. | Owner decision. |
| 2026-10-26 | Public repo under AGPLv3. | Owner decision, so JUCE is free to use. |
| 2026-10-26 | Default key is A minor. | Owner decision. |
| 2026-10-26 | Release installer is a `.dmg` containing the signed, notarized `.pkg`. | Owner decision; the spec had `.pkg` only. |
| 2026-10-26 | JUCE 9.0.4 instead of JUCE 8. | JUCE 9 is the maintained line and 9.0.4 meets the two-week rule; JUCE 8 only receives security patches. |
| 2026-10-26 | Bundle id `com.markstent.magicdust`, codes `Mdus` and `Mdst`. | Fixed identifiers for the plugin. |
| 2026-10-26 | Engine uses integer arithmetic only (weights in thousandths, swing in permille). | Goldens match on every architecture. |
| 2026-10-26 | Idea code layout (Task 5) is 13 characters and does not yet carry pins or rerolled lane seeds. | Revisit in Phase 2 when pins exist. |
| 2026-10-26 | Phase 1 generator simplifications: close-position voicings only, chord rhythm cells used as-is (no energy density scaling), flavour stored but not applied, velocity humanize only (no timing humanize), riff and call-and-response bass not yet generated. | Each is replaced in its later phase. |
| 2026-10-26 | Chord rule: every chord is in key for the chosen mode, or borrowed from one related mode with the same home note (phrygian and aeolian, aeolian and dorian, mixolydian and ionian). A progression borrows from at most one mode. The mode is chosen only among the entry's modes where the whole progression passes; an entry with a progression that passes in none of its modes is rejected when the bank loads. Parallel (chord memory) entries are exempt. | Owner decision. |
| 2026-10-26 | Melody rhythms come from a new bank field `melodyRhythms` (rhythm cells only, no pitches). Energy picks the cell whose hit count per 2 bars is nearest `3 + 7 * energy / 100`. | Owner decision. Fills the gap where the spec says melodies use "a rhythm cell from the bank" but the entry format had no such field. |
| 2026-10-26 | Any Mac DAW, not only Ableton. v1 is tested in Ableton Live, Logic Pro or GarageBand, Reaper, Bitwig, Cubase, Studio One and FL Studio. Interface and docs say "your daw" instead of "ableton". Windows stays out of v1. | Owner decision. |
| 2026-10-26 | Sound source: the owner can hear ideas through the built-in sounds or through their own instruments, live, while sprinkling. The plugin declares MIDI output from Phase 0 and sends chords, bass and melody on MIDI channels 1, 2 and 3. How each DAW receives it is settled by the routing spike (Task 3a) before Phase 2's playback plan. The choice is per lane: each lane plays either its built-in sound or sends MIDI to the owner's instrument, default built-in. The control lives on or beside each lane label; its exact look is designed in Phase 5 and added to the visual spec. | Owner decision. Changing MIDI output later can break saved sessions. |
| 2026-10-26 | Bass patterns grow from 5 to 8: rolling offbeat, offbeat, octave bounce, garage skip, sustained, riff, pedal, call and response. Riff is its own syncopated line from scale tones; pedal holds the home root under changing chords; call and response places notes in the gaps between chord hits. The visual spec's bass encoder list grows to match. | Owner decision. |
| 2026-10-26 | Chord names use the fixed spelling C C# D Eb E F F# G Ab A Bb B. | One spelling everywhere keeps output and tests predictable. |
| 2026-10-26 | "pull back" is the feel word for a degree-5 chord in the last slot of a progression of 4 or more chords; all other feel words come from degree. | Keeps feel words consistent with how progressions resolve. |
| 2026-10-26 | Settings groove sets swing; the bank entry's `swing` is stored but unused until Phase 2 decides how they combine. | Defers the combination rule until playback exists. |
| 2026-10-26 | clang-tidy check `cppcoreguidelines-owning-memory` is disabled. | JUCE requires `createEditor` and `createPluginFilter` to return raw owning pointers, so the check fires on every plugin. |
| 2026-10-26 | Close-position voicings fold chord extensions into one octave above the root, so a 9th sits between the root and the 3rd, and inversions rotate that stack. | Stacking in raw interval order made 9th chords wider than an octave and left some with no voicing in the top-note range. |
| 2026-10-26 | Triads double the root an octave up; when no such voicing fits or the cheapest one moves a voice more than 7 semitones, any triad tone may be doubled an octave up or down. | Some triad-after-7th progressions had no voicing within the 7 semitone voice-movement limit. |
| 2026-10-26 | The mud rule means the lower note of any adjacent pair below MIDI 52 sits at least 5 semitones under the upper one, which also rules out 3rds below 48; validate reports at most one line per voicing. | One simple test covers both spec rules. |
| 2026-10-26 | Voicing ties go to the lowest cost, then the lowest top note, then the lowest notes; parallel entries move the first voicing by the signed root movement (-6 to +5) in the octave that moves least and fits, else use the cost choice. | Keeps every choice deterministic. |
| 2026-10-26 | Bass octave bounce uses the root plus 12 when that stays within 48, otherwise the root minus 12 when that stays within 28, otherwise the fifth (roots with pitch class 1 to 3); the fifth is the root plus 7, or minus 5 when above 48. | The brief's R+12 leaves the 28 to 48 bass range for roots above 36, and pitch classes 1 to 3 have no octave pair in range. |
| 2026-10-26 | An entry whose bass patterns are only riff or call-and-response gets the offbeat pattern for now. | Those two patterns arrive in a later phase. |
| 2026-10-26 | The home chord is the first chord of degree 1 (else the first chord); a pedal bass holds the key's root. | Gives the melody ending and the pedal one fixed meaning of home. |
| 2026-10-26 | The mode is chosen from the entry's whole progression as before, and `borrowedFrom` is checked on the chords actually placed in the idea (a truncated progression may need no borrowing). | validate checks the same placed chords, so the two always agree. |
| 2026-10-26 | Chord lane notes also end at the next hit of the same chord, not only at the chord end. | Swing can push a 16th past the next onset, which would overlap notes of the same pitch. |
| 2026-10-26 | Melody pitches come from per-onset pools (strong beats the allowed chord tones, other steps the key scale, the last note the home chord tones when any are allowed) with a backward reachability pass, so a leap of more than 7 semitones is never needed. | A sparse pool near the range edge could otherwise leave no legal next note. |
| 2026-10-26 | Melody and rhythm ties: among cells equally near the energy target one is picked with the melody stream, cell B is a different cell chosen the same way (or A when the entry has one cell), and pitch ties go to the pitch nearer the previous note, then the lower one. | Keeps every choice deterministic. |
| 2026-10-26 | Every lane draws only from its own seed: `Pcg32(laneSeed, slot)` with a fixed slot per use (table in `engine/src/internal.hpp`). The chords lane owns the entry, progression, mode and chord-cell choices; velocity humanize draws one value per note in event order from each lane's own seed and humanize slot (chords 3, bass 0, melody 4); vocal-chop tones use melody slot 3. `generate` takes optional `LaneSeeds` so a lane reroll changes only that lane's seed. | Spec section 4: rerolling the bass never changes the melody's random stream. A shared humanize stream would have tied the lanes together. |
| 2026-10-26 | A lane's `pattern` is the chord rhythm cell id for chords, and the pattern name for bass and melody. | Gives the encoders and the UI one readable label per lane. |
| 2026-10-26 | Bass and melody notes must be in the key scale or in a chord tone of the chord sounding at their start; chord lane notes must be in the key scale or the borrowed scale, and must also be in the voicing of the chord sounding at their start. | The validation rule from the spec, made exact. |
| 2026-10-26 | For parallel (chord memory) entries the melody's no-clash tones, vocal-chop tones and final-note rule use the voicing that actually sounds, and validate accepts bass and melody notes from it. | The shape moves with the root and can leave the chord symbol, so clashes are judged against what is heard. |
| 2026-10-26 | Vocal-chop tones are picked from the home chord's allowed tones (the first onset's chord is not used). | Matches the brief: the chop pitches belong to the home chord. |
| 2026-10-26 | clang-tidy check `readability-trailing-comma` is disabled, and CI fails when the Homebrew clang-format major version differs from `.llvm-version`. | clang-format owns formatting and the check flips between LLVM versions; the lint tool version was unpinned between machines, so drift is now caught explicitly. |
| 2026-10-26 | MIDI files put chords on channel 1, bass on 2 and melody on 3, and a single-lane file uses its lane's channel. `MidiTrack` carries a 0-based channel (0 to 15, validated). | Matches the live MIDI-out mapping, so a file dropped on a track behaves like the plugin's output. |
| 2026-10-26 | Phase 1 melodies: hook, riff and sparse modes share one algorithm (only vocal chop differs); energy does not choose the bass pattern; flavour is accepted by md-cli but has no effect until Phase 2. | Simplest generator that meets the Phase 1 rules; each is replaced in its later phase. |
| 2026-10-27 | Phase 1 gate: the owner listened to all six TESTING.md md-cli ideas (uk-funky 1, mk-dub 2, soulful 3, bassline 48213, festival 77777, ny-groove 5) and kept all of them ("very simple, but very good"). The golden MIDI files in `tests/golden` are approved. | Owner listening test closes Phase 1. The owner wants more variety on top of this simple base, which the flavour, energy and groove controls in Phase 2 provide; the defaults stay as they are. |
| 2026-10-27 | Routing spike (Task 3a) in Ableton Live 12.4.6, with offbeat test notes on channels 1, 2 and 3. VST3: another track receives the MIDI (MIDI From = the Magic Dust track, second chooser = Magic Dust, Monitor In) and records it; the second chooser lists only Pre FX, Post FX and Magic Dust, so there is no per-channel choice. AU: not offered as a MIDI source. A headless host confirmed both formats emit the notes on all three channels. Forum reports say Live merges plugin MIDI output to channel 1. No other DAW is installed yet. | Findings decide how lanes reach the owner's instruments. |
| 2026-10-27 | Per-lane MIDI out stays in the one Magic Dust plugin. The first instance in a process is the main instance (full interface and audition sounds). Any further instance that finds a main instance running becomes a sender: a small screen with one choice (chords, bass or melody), sending only that lane, in sync, from the main instance. The owner routes an instrument track from a sender exactly as in the spike. The main instance keeps channels 1, 2 and 3 on its own MIDI out for DAWs that can filter channels. In Live this needs the VST3. Hosts that run each plugin in its own process (Bitwig by default) are checked in release testing. | Owner decision: one plugin is easier than a separate Lane plugin. Live cannot split one plugin's MIDI by channel, so each lane needs its own source. This is a spec addition. |
| 2026-10-27 | Flavour mapping: soulful keeps the bank's written chords, simple steps 9ths, 11ths and 13ths down to triads and 7ths (add9 to major), jazzy climbs up to two steps on the min, maj and dom ladders while every note stays in the key's scale or the borrowed mode's. Soulful passing sus4 chords and jazzy altered last dominants are left out until the flavour listening review asks for them. | The spec says simple is triads and 7ths, which this matches; the richer extras need listening before they are added. |
| 2026-10-27 | The default flavour stays soulful. | Soulful is the written chords, which is what the owner approved at the Phase 1 gate. |
| 2026-10-27 | Voicing shapes follow the entry's voicing style, built from the close-position stacks and filtered by the range, top-note and mud rules. Close is unchanged. Drop-2 moves the second-highest note of a 4-note stack down an octave. Organ-stab doubles the stack's lowest note an octave up (5 notes) when that fits and does not repeat a pitch, otherwise the close stack. Piano-spread puts the chord root as the lowest note with the rest of the stack at least a perfect 5th above it (a chord whose stack has no root, such as an 11th or 13th, gets the root added, 5 notes). A chord the shape cannot voice falls back to close position; if a shaped chord can only leap from the previous one, the whole progression is voiced in close position. Parallel entries shape only the first chord and move that shape. Voicings are now 4 or 5 notes. The golden MIDI files changed again and need owner approval at the phase gate. | Ruling 3 of the Phase 2 plan: the entry's voicing style should be audible. |
| 2026-10-27 | The sub bass and soft lead audition voices come forward from Phases 3 and 4 into Phase 2, with the organ (`plugin/AuditionSynth`); the bass and melody generators stay as they are until their phases. | Owner request, to hear all three lanes sooner. |
| 2026-10-27 | Ruling 5: one process-wide `Link` publishes each instance's playback pattern; the audio thread reads a raw pointer once per block and the message thread frees retired patterns at least a second later. The flavour parameter defaults to soulful, groove to straight, and preview and MIDI out play from the host position when the host plays, else from an internal clock the play key starts. | Keeps the audio thread free of locks and allocation, and keeps the default flavour the one the owner approved. |
| 2026-10-27 | The processor releases every sounding note when the transport stops or jumps: a host position more than 0.05 beat from where the last block ended counts as a locate or loop. Suspending (`releaseResources`) or re-preparing also releases on the next block. | A loop or locate would otherwise leave notes stuck until their next off, up to a whole pattern pass. |
| 2026-10-27 | The processor state round-trip test compares lane events, lane seeds and the pattern size rather than MIDI file bytes. | The plugin test binary does not link the MIDI exporter; identical lane events give identical bytes. |
